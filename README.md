# homebrew-tap

Homebrew formulae and casks.

| Package | What it does | Install |
|---|---|---|
| [tagteam](https://github.com/michaelrigart/tagteam) | Multi-account switcher for AI coding agent CLIs | `brew install michaelrigart/tap/tagteam` |
| [Linger](https://github.com/michaelrigart/linger) | Keeps the computer active without blocking light/dark switching (Apple silicon, macOS 26 or later) | `brew install --cask michaelrigart/tap/linger` |

Linger is not notarized, so macOS blocks its first launch: allow it once under System
Settings → Privacy & Security → **Open Anyway**. Its
[README](https://github.com/michaelrigart/linger#readme) has the details.
